# Stop After Two Failures

When working on code changes, track consecutive failed modify-and-test attempts for the current task.

If consecutive attempts fail more than 2 times:

- Stop running further edits or tests immediately.
- Report the observed error messages or failure symptoms.
- Explain the most likely cause and what evidence supports it.
- Ask the user how to proceed before trying again.
